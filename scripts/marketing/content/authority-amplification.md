# Authority Amplification

## Purpose
Amplify brand authority through strategic content and partnerships.

## Step-by-Step

### Step 1: Authority Audit
```bash
opencode run --agent "audit authority: backlinks, mentions, citations" --file content/authority-audit.md
```

### Step 2: Strategy
```bash
opencode run --agent "plan: PR, thought leadership, partnerships" --file content/authority-strategy.md
```

### Step 3: Execution
```bash
opencode run --agent "execute: guest posts, PR, speaking" --file content/authority-execute.md
```

## Amplification Tactics
- Guest blogging
- Podcast appearances
- PR campaigns
- Industry partnerships
- Thought leadership
- Data studies
- Awards submissions
